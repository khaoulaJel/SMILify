SMILify Morphometric Validation

A number extracted from an articulated fitted model is not automatically a morphometric. Four validity axes, which fail independently — corpus: 20 Atta vollenweideri, ARM A fit.

B1 ANATOMICALDo the endpoints sit on the structure the trait is named after? Needs expert landmarks.
B2 POSE INVARIANCEDoes it hold constant when only articulation changes, shape fixed? Needs nothing but a fit.
B3 BIOLOGICALDoes it reproduce a known scaling relationship? Needs reference measurements.
B4 CONSISTENCYBilateral asymmetry |R−L|/mean. Needs no ground truth — computable on all 757.
Why four axes and not one. A measurement can be perfectly pose-stable and still anatomically wrong — measuring the wrong structure, consistently. That is exactly what R3/R4 found (34.7% → 0.2% anatomical error the moment supervision names the correct part, with surface error unchanged at 0.2% either way). Any single axis certifies fits that are wrong.

B2 — pose invariance

Same specimen, joint rotation zeroed, betas / per-joint scale / per-joint translation / deform_verts held exactly as fitted. Only articulation varies, so the difference is pure pose contamination. Green ≤0.5%, red >2%.

B3 — biological validity

Read the null as 1.0, not 0. load_meshes normalises every specimen independently, so model-unit traits carry no absolute size. Physical scale is restored per specimen via BLmm/BLmodel; because that factor contains body length, a trait with no independent size information lands at exponent ≈1.0. Deviation from 1.0 is the signal — not R², which is inflated by the shared factor.

Positive control: reference head width vs reference body length (both directly measured, no model involved) → exponent 1.2352 [1.164, 1.306], R²=0.9868, published 1.2352 — PASSES. If this control fails, nothing below is trustworthy.

Blue = CI excludes isometry (independent size signal); grey = isometric. Dashed blue = the published Atta head-width exponent.

B3b — measurement agreement against the physical reference

Why this is separate from the allometry check above. "Reproduces the expected biological scaling" is evidence of validity but is not a measurement-accuracy test: R²=0.99 coexists happily with large systematic bias. Morphometric methodology treats biological signal and measurement error as separate things, established separately. This section measures agreement — bias, limits of agreement, proportional bias, Lin's concordance — not correlation.
Read the circularity column first. Model traits live in a per-specimen normalised frame, so physical scale is restored with scale = BLmm/BLmodel. That factor comes from body length, so BL agreement is exactly circular (an arithmetic check, not evidence) and HW-in-mm is partially circular. The dimensionless HW/BL ratio is the only fully independent test — the factor cancels. That is the row that means something.

Three things this surfaced that R² could not. (1) The two "head width" definitions are not interchangeable — the reporter-bone distance is essentially unbiased (−0.13%) while the Type III extent carries a systematic +2.22% bias. (2) Concordance collapses from 0.996 → 0.862 once size is removed, so the near-perfect agreement in mm is largely carried by the shared scale factor — the circularity made quantitative. (3) The scale-free HW/BL ratio shows significant proportional bias (p=0.044): error grows with specimen size. That is the same defect as the recovered exponent coming in at 1.205 against the published 1.2352 — the model slightly compresses the allometric relationship. Two independent methods, one real finding.

B4 — internal consistency, and can it stand in for the rest?

Ants are near-symmetric, so measured left–right disagreement is pipeline error, not biology. This is the only axis needing no ground truth, so it is the only candidate for a deployable confidence criterion on an unannotated corpus.

No — not per specimen. Every correlation is non-significant (p ≥ 0.10). Asymmetry does not tell you whether a given specimen's measurement is pose-contaminated. It does rank correctly across traits (SL is worst on both axes), so B4 is a usable trait-level screen and not a per-specimen confidence score. Reporting it as the latter would be the exact proxy-without-mechanism error this project has hit seven times.

B1 — anatomical validity

The traits are still computed at unadjudicated landmarks. trait_extract.py reads landmark_template_indices.json, which is rule-computed and explicitly source:"verify" — never anatomically adjudicated. The expert-recalibrated file moves those exact vertices by 7.8–14.7% of the body diagonal (SL worst at 14.65%). Every trait number computed today carries that offset. petiole_* and gaster_apex_mid have no expert annotation at all, so PetL / GL / TBL cannot be validated on this axis even in principle.
