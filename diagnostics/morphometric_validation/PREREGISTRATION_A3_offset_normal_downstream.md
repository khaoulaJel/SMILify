# Pre-registration — A3: does A1's fix survive into a real fit and real measurements?

**Written and committed BEFORE the run.** Bars fixed here are not revised after seeing a number.

Date: 2026-09-09.

---

## 1. The gap A1 explicitly left open

A1 showed removing `w_offset` + `w_normal` reverses the objective's hostility to correct anatomy
(+67.1% -> -12.9%) at *better* chamfer (0.673x). But A1's CORRECT arm was **landmark-supervised in
every configuration** — it measured whether the objective *fights* the right answer, not whether an
unsupervised fit *finds* it. A1's own limits section says exactly this.

Nobody has run an unsupervised fit under those weights. A3 does.

> **H: fitting with `w_offset = w_normal = 0` produces measurably better MORPHOMETRICS than the
> production recipe, without degrading vertex correspondence.**

## 2. Why the endpoint is morphometric error and not chamfer

M2 established that chamfer does not predict morphometric accuracy (|r| <= 0.34 across nine traits,
and even oracle diagnostics reach only ~0.41). So a chamfer-based verdict here would be
uninformative by our own measurement. The endpoint is trait recovery error against known
ground truth, which `synth_power48` supplies exactly.

## 3. Design

- **Corpus**: `diagnostics/moonshot/synth_power48` (48 specimens, `noise = 0.0`, generated by the
  model, so an exact solution exists in the search space; shared topology gives TRUE per-vertex
  correspondence error, not a proxy).
- **Arm A**: `A3_prod.yaml` = `D1_PROD.yaml` verbatim (w_offset 5.0/2.0, w_normal 0.005/0.002).
- **Arm B**: `A3_nooffnorm.yaml` = identical except those four weights set to 0.
- `diff` verified: the two configs differ in exactly those four lines plus `results_dir`.
- **`D1_PROD` is used, NOT `D1_no_deform`**, because `w_offset` penalises `deform_verts`; with
  deformation disabled the intervention would be vacuous.

## 4. Endpoints and pre-registered bars

**Primary — morphometric recovery.** Median across traits of the per-specimen scale-corrected trait
error (M2's `trait_error_shape_only`), arm B vs arm A, paired across 48 specimens.

- **PASS** — arm B's median trait error is lower, by >=10% relative, with paired sign test p<0.05,
  **and** the correspondence guard below holds.
- **PARTIAL** — improves significantly but by <10% relative, guard holding.
- **FAIL** — no significant improvement, or the guard fails.

**Correspondence guard (gating, not advisory).** True per-vertex correspondence error
(`mean ||v_fit - v_gt||`, available because topology is shared) must not degrade by more than **5%**
relative in arm B. `w_offset` exists precisely because unbounded `deform_verts` destroys
correspondence (Z4/Z5: deform is per-specimen noise; `trainer_moonshot.py`'s own rationale). If
anatomy improves while correspondence degrades, the fix is illusory and this is the check that says
so. **This is the most likely way A3 fails and it is stated before the run.**

**Reported alongside, gating nothing**: chamfer (for continuity with A1, not as evidence),
mean `||deform_verts||` (does removing the bound blow the offsets up?), per-trait breakdown.

## 5. What each outcome licenses — fixed now

| outcome | reading |
|---|---|
| PASS | A1's objective fix is real and reaches measurements. First intervention in this project to move morphometrics. Candidate recipe change, pending corpus-scale + real-scan tests |
| PARTIAL | direction confirmed, magnitude small — report as a Pareto point, not a recipe change |
| FAIL, guard held | the objective's preference was not the binding constraint on an unsupervised fit; search/identity is. Strengthens the R12 direction over further objective work |
| FAIL, guard broken | removing `offset` buys anatomy by destroying correspondence — exactly the trade Z4/Z5 predicts. `offset` is load-bearing and A1's result does not transfer |

## 6. Not claimed

Synthetic, in-model, noise-free, shared topology. Real scans add fragmentation and out-of-model
morphology. A PASS is a necessary, not sufficient, condition for a production recipe change — and
Task 7/Intervention C's stratified-sampling null is the standing reminder that interventions which
look good on one metric here have repeatedly failed to move correspondence.
