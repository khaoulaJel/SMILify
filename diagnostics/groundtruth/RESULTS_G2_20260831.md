# G2 — the report's reliability certificate does not survive real ground truth

The table in `REPORT_MORPHOMETRICS.md` §2.2 decides which measurements the report trusts. It sets
`CORE_BLOCKS`, and therefore what gets published as a morphological finding. It was computed on
**12 synthetic specimens generated from the model itself** — in-distribution by construction, the
same trap that made ALL_ANTS_CLEAN an invalid control in Z1.

Ten human-annotated real specimens allow it to be checked for the first time.

## Result

Bone lengths are `|J[child] − J[parent]|`, computable directly from annotated joints, with
`measure.py`'s own `bone_table` supplying the parent/child pairs — the same code path for truth and
fit, so a discrepancy is a property of the fit. Both sides go through Mosimann log-shape-ratios,
because absolute size is not recoverable from worker scans (§2.1) and each annotation lives in its
own scan's arbitrary units.

| block | features | **real R** | §2.2 synthetic R | drop | median bias | P(median ≤ obs) |
|---|---:|---:|---:|---:|---:|---:|
| mandible | 2 | **0.508** | 0.608 | 0.10 | −0.574 | 0.31 |
| leg_prox | 24 | **0.032** | 0.756 | **0.72** | +0.094 | **<0.0001** |
| gaster | 5 | −0.048 | 0.597 | **0.65** | −0.018 | **<0.0001** |
| leg_distal | 12 | −0.126 | 0.136 | 0.26 | −0.049 | **0.0092** |
| antenna | 6 | **−0.127** | 0.759 | **0.89** | −0.138 | **<0.0001** |

**Median R across all 49 features: −0.048. Twenty-five of 49 are ≤ 0; only one reaches 0.5.**

The P column is a simulation: for each block, draw the same number of features at the same sample
size from a population whose true correlation is the synthetic value, and ask how often the median
falls this low. At n = 14 a single correlation still has a 95% interval of roughly ±0.53, so individual
features are uninformative — the aggregate is what carries the result.

**§2.2's calibration is rejected for antenna, gaster, leg_prox and now leg_distal too.** It
survives only for **mandible**.

**The range-restriction alternative is dead.** At n = 10 the annotated set contained no specimen
from the worst-fitting quartile and lacked both poles of the head/scape axes, so a defender could
argue the antenna block's R ≈ 0 was attenuation from restricted spread rather than fitter error.
Adding *Cephalotes* (scape_index min, cephalic_index max), *Eciton* (scape_index max),
*Discothyrea* and *Acromyrmex* closes both gaps — and antenna R moved from 0.005 to **−0.127**.
Widening the range made it worse, not better. Attenuation was not the explanation.

## Why the synthetic number was wrong

`calib_features.py` correlates **raw** measurements — verified, there is no `log_shape_ratios`
step. On synthetic specimens the fit and the truth share one absolute scale, so a large ant has a
long everything in both, and correlation runs toward 1 for every feature whether or not shape was
recovered. **§2.2 was largely measuring size agreement, not shape recovery.**

That also reconciles two numbers that never fitted together: §2.2's head R = 0.958 against Z8's
real repeatability of 0.149. They were never the same quantity.

On real specimens the synthetic method is not merely optimistic, it is **not computable** — there
is no shared absolute scale to correlate. Proportion is the only thing the corpus supports, and in
proportion the fitted measurements do not track the true ones.

## Bias: the n = 10 claim did not survive, and that is worth recording

An earlier draft of this file, at n = 10, reported median bias of −0.16 to −0.24 log units and
concluded that fitted proportions are systematically 16–24% small, therefore that errors do not
average out and population-level claims fail. **Four additional specimens moved those estimates
substantially** — gaster −0.241 → −0.018, leg_distal −0.162 → −0.049, antenna −0.227 → −0.138 —
so that conclusion was not robust and is **withdrawn**.

| block | bias n=10 | bias n=14 | change |
|---|---:|---:|---:|
| gaster | −0.241 | −0.018 | +0.223 |
| leg_distal | −0.162 | −0.049 | +0.113 |
| antenna | −0.227 | −0.138 | +0.089 |
| leg_prox | +0.032 | +0.094 | +0.062 |
| mandible | −0.564 | −0.574 | −0.010 |

**The correlation result strengthened with more data; the bias result moved.** That asymmetry is
itself informative: R is estimated from 49 features jointly and is stable, whereas a per-block
median bias at n ≤ 14 is not. **Bias remains the decisive open question** — it determines whether
comparative claims survive — and it needs either more specimens or a paired design before it can
be stated. Only the mandible bias (−0.57, stable to ±0.01 across both samples) is currently
trustworthy, and it is large.

## What this means for the report

- **§2.2's table should not be used** to certify blocks as reliable. It measures the wrong quantity
  on the wrong corpus.
- **`CORE_BLOCKS` is not supported** by the evidence it cites. `head`, `mandible`, `antenna`,
  `leg_prox`, `mesosoma`, `gaster` were selected on synthetic R; of the four testable here, three
  fail and one holds.
- **§9's guidance inverts in part.** "Use it for genus- and subfamily-level comparative work on
  head, mesosoma and gaster proportions" — gaster is the *worst* block against real truth
  (R = −0.054, bias −0.24). Its stated support, "ground-truth calibration", is the synthetic table.
- **§9's "do not use it for leg proportions" stands**, and now stands on real evidence.
- **The mandible block survives** — the only one that does. `attach_ma_l` R = 0.532,
  `attach_ma_r` R = 0.509, consistent with the synthetic value. §4.2's mandible-slenderness
  finding is the report's best-supported morphological claim.

## Limits, stated plainly

- **n = 14**, 11–14 specimens per feature. Individual R values are not interpretable; only the
  block-level and overall aggregates are. Per-block *bias* is not yet stable at this n (see above).
- The simulation treats features as independent. They are not — bilateral pairs are strongly
  correlated — so the P-values are somewhat optimistic. The effect sizes (0.72 and 0.75 drops) do
  not depend on that.
- **No annotation-repeatability control.** Some of the real R ≈ 0 could be annotator placement
  noise rather than fitter error. With range restriction now excluded, **this is the last standing
  alternative explanation**, and it is one hour of blind re-annotation to settle.
- **The head block is untestable from joints.** There is no head bone — `b_h` is coincident with
  `b_t` (the neck pivot convention), so `bone_table` drops it. Head dimensions in the report are
  mesh-derived, and testing them needs annotated head landmarks (width, length) rather than joints.
  **§2.2 rates head the most reliable block of all at R = 0.958, and it is precisely the one this
  cannot check.**

## The two things worth annotating next

1. **Re-annotate 2–3 specimens blind** — now the single highest-value hour available, because it
   is the only remaining alternative explanation for the near-zero correlations.
2. **Annotate head landmarks** (maximum head width, head length, and the mandible tips) as explicit
   points rather than joints. That would test the report's highest-rated block and its headline
   §4.1 cephalic-index finding, neither of which any joint annotation can reach.
