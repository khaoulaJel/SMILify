# G13 — against expert ground truth, the fitter is nearly UNBIASED and carries almost NO signal

Fabian's expert-corrected joint annotations (`annotation/gt_expert/`, n = 12) replace the novice
placements G1 and G2 were built on. Same code path throughout (`g2_real_reliability.py`, only the
truth directory changes), so any difference is a property of the annotation, not the analysis.

**The sample changed too (14 → 12), so every comparison below is against the novice annotation
restricted to the SAME 12 specimens.** Without that control the mandible result is uninterpretable.

## The two findings

### 1. Bias was mostly the annotator, not the fitter

| block | novice bias (same 12) | **expert bias** | shrink |
|---|---:|---:|---:|
| gaster | −0.320 | **−0.041** | 7.8× |
| mandible | −0.551 | **−0.114** | 4.8× |
| antenna | −0.135 | **−0.024** | 5.6× |
| leg_distal | −0.129 | **−0.026** | 5.0× |
| leg_prox | +0.129 | **+0.071** | 1.8× |

**Against correct truth the fitter is close to unbiased on every block.** G2's bias figures — already
withdrawn once for instability between n=10 and n=14 — were largely measuring placement error.

### 2. The correlations do not move. They were never the annotator's fault.

| block | novice R (same 12) | **expert R** | synthetic §2.2 |
|---|---:|---:|---:|
| leg_prox | 0.076 | **0.053** | 0.756 |
| gaster | −0.018 | **−0.028** | 0.597 |
| leg_distal | −0.017 | **−0.032** | 0.136 |
| antenna | −0.084 | **−0.044** | 0.759 |
| **mandible** | **0.482** | **0.246** | 0.608 |

**Median R across 49 features: 0.016 → 0.011. One feature of 49 reaches 0.5.**

G2's last standing alternative explanation — that the near-zero correlations were annotator noise —
is **eliminated**. Expert truth reproduces them.

### The mandible block, G2's only survivor, does not survive

**0.482 → 0.246 with the sample held fixed**, so this is an annotation effect, not sampling. The
mandible was one of the two regions Fabian corrected substantially (the other being the coxa).
§2.2's `CORE_BLOCKS` now has **nothing** left: head untestable, mandible failed, antenna, gaster,
leg_prox and leg_distal all failed.

REPORT §4.2's mandible-slenderness finding was described as "the report's best-supported
morphological claim". It rested on novice mandible placement and does not hold against expert truth.

## What this means, precisely

Insight IV distinguishes two failure modes with different consequences. This resolves which one we
have, and it is the more forgiving one:

- **Near-unbiased** → errors average out, so *population-level* aggregates remain defensible.
- **R ≈ 0** → the measurement does not rank specimens, so *per-specimen and comparative* claims fail.

**SMILify's joint-derived proportions support population means and not specimen ranking.** That is a
narrow but honest and usable statement, and it is the first one in this project backed by expert
ground truth.

It also coheres with everything else measured: G1 (the fit is 17% better than the population-mean
template), WL varying only 8.7% CV across 757 morphologically extreme ants, and T3 (no intervention
could raise genus discriminability). All four say the same thing — **the fit regresses heavily
toward the template**, producing average morphology with little specimen-specific content.

## The one positive, and where it points

Coxa features now top the table (`seg_l_1_co_l` R = **0.550**, `seg_l_1_co_r` 0.471) — the region
Fabian corrected most. Real, but one feature above 0.5 out of 49 is not a recovery.

The forward-looking distinction: **every measurement scored here is joint-derived** — distances
between rig rotation pivots. On the same fitted meshes, *mesh-surface* traits behave differently:
the GLAD cephalic index separates *Cephalotes* from *Odontomachus* at **1.92×, Cohen's d = 2.19**,
with the ordering predicted from taxonomy rather than from the pipeline.

That contrast is suggestive, not established — genus separation and correlation-with-truth are
different criteria. **Testing it needs the expert trait landmarks** (HL, HW, WL, ML, SL), which this
joint annotation cannot reach. That is now the single highest-value outstanding request.

## Limits

- **n = 12.** Block-level aggregates only; individual R values are not interpretable at this size.
- **Bias is more stable than before but still n = 12.** Report it as "small" rather than as a value.
- **Head is still untestable from joints** (`b_h` coincident with `b_t`, no head bone), and §2.2
  rates it the most reliable block of all.
- No annotation-repeatability estimate exists and none is recoverable here: the novice pass was not
  a competent independent attempt, so novice-vs-expert distance measures correction, not observer
  variability. Stated as a limitation rather than manufactured.
