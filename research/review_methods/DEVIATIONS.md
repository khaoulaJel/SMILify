Dated, append-only. Each entry says what changed, why, and whether any result had been seen that the
change could favour.

## D1 (2026-10-06): changes from the rules audit (`RULES_AUDIT.md`)

Made before any new method had produced any number. No result exists that these changes could favour.

1. **R1** Report the mean over joints alongside the median (MPJPE comparability). Verdicts still use
   the median, as frozen.
2. **R2** Add the Bayesian signed-rank test (Benavoli et al. 2017; Dirichlet-process prior, ROPE =
   SESOI = 2.5% WL) as a secondary summary for every JAB contrast: P(better), P(equivalent),
   P(worse). The frozen Holm verdict remains the verdict.
3. **R5** Synthetic fitter arms run 3 seeds (0, 1, 2), not >= 2.
4. **R7** Primary dense-correspondence metric on synthetic becomes geodesic error / sqrt(template
   surface area) with cumulative error curves (Kim et al. 2011 protocol); the Euclidean
   rest-space / segment-length metric is kept as secondary for continuity with C11/F-series.
   `diagnostics/correspondence_accuracy/geodesic.py` must be verified before use.
5. **R9** Real-scan proxy correspondence numbers get a sensitivity check that corrects for proxy
   error using the synthetic gate's confusion matrix.
6. **R14** Synthetic body length L = sum of GT body-axis bone lengths (b_t -> b_a_1 -> ... -> b_a_5
   FK chain), not the GT bounding-box diagonal, because the diagonal depends on leg pose.

## D2 (2026-10-06): Q3b S1 corruption is spatially coherent

Made before any S1 target file existed. The pre-registration says "a fraction rho of leg vertices".
Implemented as a fraction rho of the 24 (leg, segment) units (tr, fe, ti, ta+pt on six legs), each
corrupted unit redirected as a whole to the adjacent same-side leg. Reason: real CSE errors are
patches of a region assigned to another leg (A2), not independent per-vertex flips; iid flips would
test a different, easier error (salt-and-pepper targets a smooth model averages out). rho levels
unchanged. Vertex mapping between legs: rest-template translation by the segment's proximal joint,
then nearest vertex of the same segment on the target leg.

## D3 (2026-10-06): S2 gains four factorised real-parameter conditions

Made before job 4806679 started (no S2 output existed). Reason: Q3a A8 showed real pinned specimens
hold their distal legs far closer to the body (15.9-59.4% WL to non-leg surface on 8/11) than
synthetic specimens (74-137% WL); isotropic random poses (ART) test articulation magnitude but cannot
produce that folded structure. New conditions put the parameters of the 33 JAB `A_prod` final fits
(11 specimens x 3 seeds) onto clean model surfaces, one factor at a time:

- REALPOSE  joint_rot from the real fits; betas / scales from the training generator
- REALSHAPE betas from the real fits; pose / scales from the training generator
- REALSCALE log_beta_scales + betas_trans from the real fits; rest from the training generator
- REALALL   betas + joint_rot + log_beta_scales + betas_trans from the real fits (global_rot 0, no deform)

Disclosure: these use JAB fit parameters as *input conditions* for the network, not any
method-performance result. Added decision reading (no change to the H-artic rule): the factor
whose condition reproduces the real signature (leg accuracy <= 0.80, wrong-number >= 2x wrong-side,
cycle >= 2x C0) is named as sufficient; if only REALALL reproduces it, the factors interact; if none
does, the gap is attributed to the scan surface (geometry not generated by the model), which
synthetic data cannot reproduce.

## D4 (2026-10-07): Q2 runs on two regimes

The pre-set Q2 regime rule produced a tie it could not break unambiguously: REALSCALE (|0.665 - 0.695|
= 0.030) and REALPOSE (0.037) lie within the 0.02 tie band, and "fewer modified factors" depends on
whether log_beta_scales + betas_trans count as one factor or two. Choosing after seeing S2 would be a
post-hoc choice, so Q2 runs both regimes and reports both. No Q2 result existed.

## D5 (2026-10-07): S2 and Q2 become two-tier, pilot (JAB poses) and confirmatory (independent corpus)

Reason (user request to scale where the data are limiting, checked against the literature): S2's
REAL* conditions and Q2's regimes draw real articulation from only the 11 JAB specimens, which are
also the final test set; too few poses, and a leakage path into any later training. Body-model
synthetic-to-real practice (SURREAL, AGORA, BEDLAM) draws synthetic poses from a large corpus of real
poses. New folder `P0_real_pose_corpus/` (pre-registered) fits 657 worker scans from 161 genera,
excluding every JAB genus, split genus-disjoint into pose_train (521 specimens, 116 genera) and
pose_eval (136, 45). S2 and the queued Q2 (jobs 4845052/4845053) are now the disclosed **pilot**;
S2-confirm and Q2-confirm on pose_eval are the confirmatory tests and the ones the paper cites.
Q2's pre-registered regime rule and decision rules carry over unchanged. Decided after S2's pilot
result was seen; the confirmatory rules are those already frozen, so this cannot favour an outcome.

## D6 (2026-10-07): Q2 oracle re-optimisation uses production's own Stage_3 machinery, not JAB's oracle loop

Made before any Q2 oracle run. Q2's pre-registration said "follows JAB's oracle protocol (Adam,
lr 0.005)". Checked against the production code (rules audit, R16): JAB's oracle loop uses lr 0.005,
10x the production Stage_3 rate (0.0005), drops the joint_rot custom lr (0.002), and optimises only
global_rot / joint_rot / betas / trans / deform_verts, while production `scheme: all` also optimises
log_beta_scales and betas_trans. Q2 therefore re-optimises with a `MoonshotStage` subclass built from
the exact A_prod.yaml Stage_3 options (800 iterations as pre-registered), adding only the oracle term.

Also found by probe before writing the tool: the root joint's log-scale is not a global scale
(GT params + root log-scale = -log(sc) miss the normalised GT mesh by 3.2e-2), so GT parameters cannot
be copied into a fit. O-pose / O-shape use GT parameters expressed in the fitter's frame by exact
registration to the normalised GT mesh (known vertex identity), initialised at the GT parameters; the
registration residual is reported and must be small for those arms to be interpretable.

## D7 (2026-10-07): wording and scope corrections from the second review (REVIEW2_RESPONSE.md)

No result is changed; claims are narrowed.
1. P0 is a **real-scan fitted-pose library**, not an "independent real-pose corpus": its poses are
   D1_PROD fits, not ground truth. "Independent" applies only to specimens/genera (disjoint from JAB).
   Every P0 use carries its validity-gate result (fitted vs expert articulation on JAB), and the P0
   training experiment adds a broadened-synthetic arm (C) that does not depend on the fitter.
2. "Articulation is the dominant **tested** source of correspondence degradation" (S2 is synthetic
   and PARTIAL), never "the cause".
3. "Real shapes are inside the training distribution" holds **in the model's 25-PC shape space
   only**. Out-of-model morphology is untested and is the leading candidate for the unexplained
   Cephalotes/Discothyrea cycle distances. LOMO moves to Tier 2 with that limit stated.
New experiments from the review, each pre-registered in its own folder before running: Q3c identity
trajectories (now), Q3d identity-weight sweep, M04 with per-iteration identity, M01 hierarchical
skeleton-conditioned correspondence, M05 with an oracle arm, P0 A/B/C training distributions.

## D8 (2026-10-08): GBCPD required settings taken from the author's published demos

The M08 smoke test showed GBCPD requires a rank constraint (`-K`) the pre-registered grid did not
list, and that the triangle file must be tab-separated. Fixed by adopting the BCPD author's own
full-body GBCPD settings (`-K300 -J300 -p`, demo-python/bcpd/gbcpd_plusplus.py human-body cases),
untuned. The pre-registered grid (beta, lambda, tau) is unchanged. No GBCPD result existed.

## D9 (2026-10-08): Q4 gating rule for M04 / M02 updated after Q3c/Q3d -- POST HOC, disclosed

Q2's pre-registration gated M04 on "O-part or O-corr closes >= 40% AND S1 supports H-absorb or
H-surfterm", and M02 on "O-corr >= 40% AND S1 supports H-absorb". Both S1 hypotheses came back NOT
SUPPORTED, but the mechanism they were reaching for was then measured directly and SUPPORTED by Q3c
(H-erode: wrong targets active in the surface stages erode identity; correct ones do not) and
sharpened by Q3d (no weight rescues wrong-LEG targets; non-leg errors are nearly harmless) and Q2x
(per-specimen wrong-leg fraction predicts lost benefit, break-even ~25%).
Updated gate: an intervention that acts on wrong-leg correspondence is built if Q2's O-part or O-corr
closes >= 40% of the gap (unchanged oracle condition) AND H-erode is supported (it is). This change
was made AFTER the S1/Q3c/Q3d results and BEFORE any Q2 oracle result or any Q4 method run. It is
reported as post hoc. The JAB family stays m = 6; slot mapping: re-estimation (M04) takes the M04
slot, the leg-consistency gate takes the M02 slot (a hard confidence gate on correspondence).
